# Princess &amp; Prince Gamester

A minimal canvas playground built with Vite, React, TypeScript, and PixiJS.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

The PixiJS application is created and destroyed inside a React effect in
`src/App.tsx`. Read `AGENTS.md` before changing the project and update it when
requirements or architectural decisions change.
